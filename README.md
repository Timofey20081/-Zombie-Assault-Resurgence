## Русификатор «Зомби-штурм: Пробуждение» 4.0

Для Steam-версии Zombie Assault: Resurgence с обновлением от **13 ноября 2026**.

### Какой файл скачать

| Файл | Для кого |
|---|---|
| `ZA_Rusifikator_Setup_4.0.exe` | Windows, полная версия: перевод на выбор, русские названия и логотипы, моды |
| `ZA_Rusifikator_Setup_1.0(Lite).exe` | Windows, только перевод текста и шрифты, 2,8 МБ |
| `ZA_Rusifikator_Setup_1.0(Lite)_Linux.sh` | Linux и Steam Deck, только перевод |

### Что нового

**Перевод**
- Переработаны диалоги и фразы: сюжет, операции, пролог, разговоры на станции, заказы и способности.
- Русские названия моделей снаряжения: «РИА Т25 Воспламенитель», «Неконтактная мина Х323», «Сидэн», «Страж-Тяжеловес» и другие.
- Shotlite, Shiplite и HIKS теперь Шотлайт, Шиплайт и ХИКС.
- Поддержка обновления игры от 13 ноября, переведена новая строка «Устранение босса».

**NVIDIA DLAA**
- Сглаживание DLSS 4.5 (пресет L) вместо сглаживания игры: чёткая картинка без дрожи.
- `Ctrl+F12` включает и выключает DLAA в игре. Нужна видеокарта GeForce RTX.

**Discord**
- Статус в профиле: класс, уровень и миссия.

**Динамик DualSense**
- Реплики по рации звучат из геймпада, а не из колонок. Голос героя остаётся в игре.
- Перезарядка, способности, аптечки, кнопки меню и ящики тоже звучат из геймпада, без дублирования.
- Тачпад: выбор точки для броска гранаты и установки турели.

**Установщик**
- Стиль Windows 11, звуки и мелодия заставки из игры, гифки с демонстрацией функций.
- Новая Lite-версия для Windows и Linux.

### Установка

**Windows:** закройте игру, запустите установщик и пройдите мастер. Если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: установщик не подписан цифровой подписью.

**Linux / Steam Deck:** скачайте `.sh`, запустите двойным щелчком или командой `bash ZA_Rusifikator_Setup_1.0\(Lite\)_Linux.sh` и выберите пункт меню. Нужен python3, на Steam Deck он уже есть.

### Удаление

- Windows: «Параметры → Приложения → Русификатор Zombie Assault: Resurgence → Удалить».
- Linux: запустите `.sh` снова и выберите «Удалить».
- Или «Проверить целостность файлов» в Steam.

Если Steam обновит игру, перевод может пропасть, при этом игра не ломается. Скачайте новую версию русификатора.
